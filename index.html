接入方式

三步拿到数据

普通 GET 请求，无需注册、无需鉴权，浏览器里可以直接调用。

示例：随机一言
  1. 01
    挑一个接口

    在上方目录搜索「天气」「网易云」或按分类浏览，点开查看参数与上游文档。

  2. 02
    直接发送

    参数已填好示例值。发送后可以看到状态码、耗时、响应头与真实内容。

  3. 03
    复制到项目里

    cURL、JavaScript、Python 任选一种，粘进代码即可运行。

通用参数

__pick
从 JSON 中只取一个字段，支持点号与数组下标，如 data.songs.0.name。
__raw=1
跳过本站加工，返回上游原始响应。
__download=1
以附件形式下载图片或文件。
任意上游参数
原样透传。文档里的参数名直接写进 query 即可。
缺省参数
没传的参数自动使用示例值，所以 /api/r/weather 也能直接返回结果。

响应头

X-Router-Status
上游 HTTP 状态码。
X-Router-Latency
上游耗时，单位毫秒。
X-Router-Upstream
实际请求的上游域名。
X-Router-RateLimit-Remaining
当前分钟窗口的剩余额度。

部署到 Vercel

npm i -g vercel
vercel --prod

零依赖、零构建。静态页加三组 Serverless Function，推上去即可运行。

说明

它是一个白名单中转，
不是开放代理

API Router 把协议各异、CORS 各异的公共接口收敛成统一的 /api/r/:id 路径，并补上缓存、超时、编码转换与错误兜底。

上游地址全部写在服务端注册表里，客户端只能访问登记过的接口，因此不会被拿来打内网， 也不会替你携带任何密钥。数据版权归各上游所有，本站仅做技术中转。

43 个上游域名 白名单转发 GBK 自动转码 零依赖

  • 一个入口

    不用记几十个域名，全部走 /api/r/{id}。

  • CORS 全开

    浏览器、小程序、桌面端都能直接请求，无需代理层。

  • 错误可读

    上游超时、限流、编码异常都会转成明确的 JSON 错误。

  • 健康监测

    实时探测上游可用性与耗时，坏接口在目录里直接标出。
